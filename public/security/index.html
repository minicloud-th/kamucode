ความปลอดภัย

สิ่งที่ระบบทำ และสิ่งที่คุณควรรู้เพื่อดูแลบัญชี

รหัสผ่านและเซสชันการควบคุมการเข้าถึงการป้องกันการใช้งานผิดปกติสถานะอีเมลและการกู้บัญชีดูแลบัญชีของคุณแจ้งปัญหาความปลอดภัย

อัปเดต 31 ตุลาคม 2569

รหัสผ่านและเซสชัน

รหัสผ่านถูกแฮชด้วย scrypt ก่อนจัดเก็บ เซสชันเข้าสู่ระบบใช้คุกกี้ HttpOnly และ SameSite พร้อม Secure เมื่อใช้งานผ่าน HTTPS รหัสผ่านไม่ถูกเก็บไว้ในเบราว์เซอร์โดยเว็บไซต์

การควบคุมการเข้าถึง

ระบบตรวจสอบผู้ใช้ฝั่งเซิร์ฟเวอร์ก่อนอ่านหรือเปลี่ยนข้อมูลสมาชิก รายการบันทึก ใบสมัคร และประวัติติดต่อ ไม่อาศัยการซ่อนปุ่มเพียงอย่างเดียว

การป้องกันการใช้งานผิดปกติ

ระบบเข้าสู่ระบบจำกัดความถี่คำขอ ตรวจสอบ Origin และใช้กลไก State/PKCE สำหรับ OAuth การเข้าสู่ระบบโซเชียลจะเปิดเฉพาะผู้ให้บริการที่ร้านตั้งค่าแล้ว

สถานะอีเมลและการกู้บัญชี

ระบบบัญชีอีเมลในระยะนี้ยังไม่มีอีเมลยืนยันหรืออีเมลรีเซ็ตรหัสผ่านอัตโนมัติ สถานะอีเมลจะแสดงตามจริงในหน้าบัญชี และไม่เชื่อมบัญชีโซเชียลเข้าหากันโดยอัตโนมัติ

หากลืมรหัสผ่าน ให้ส่งเรื่องผ่านศูนย์ช่วยเหลือ การเปลี่ยนการเข้าถึงบัญชีต้องผ่านการตรวจสอบตัวตน

ดูแลบัญชีของคุณ

  • ใช้รหัสผ่านยาวและไม่ซ้ำกับบริการอื่น
  • ตรวจสอบ URL ก่อนเข้าสู่ระบบ
  • ออกจากระบบเมื่อใช้เครื่องร่วมกับผู้อื่น
  • เปิดการยืนยันตัวตนเพิ่มเติมในบัญชีโซเชียลของคุณ หากผู้ให้บริการรองรับ

แจ้งปัญหาความปลอดภัย

หากพบปัญหา ให้ส่งหน้าที่เกี่ยวข้อง ขั้นตอนที่พบ และผลกระทบที่สังเกตได้ผ่าน แบบฟอร์มแจ้งปัญหาความปลอดภัย

อย่าส่งรหัสผ่าน คุกกี้ คีย์ลับ ข้อมูลการชำระเงิน หรือข้อมูลส่วนตัวของบุคคลอื่น

นโยบายความเป็นส่วนตัวข้อกำหนดการใช้งานความปลอดภัยช่วยเหลือแผนผังเว็บไซต์
